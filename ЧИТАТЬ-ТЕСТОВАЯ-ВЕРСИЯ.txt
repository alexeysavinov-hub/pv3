ТЕСТОВАЯ ВЕРСИЯ САЙТА PCM (статика, дизайн v3 «Студия»)
=======================================================

Это отдельный самостоятельный сайт из обычных HTML-файлов — без PHP и без базы.
Его можно выложить куда угодно: Vercel, Netlify, GitHub Pages, любой хостинг.
Домен pcm2.ru не затрагивается.

ЧТО ВНУТРИ
  index.html              главная (карусель, авто в наличии, сервис, новости)
  cars/                   каталог (14 авто) + карточка каждого автомобиля
  models/                 модельный ряд
  news/                   новости (10 публикаций) + страницы статей
  service/                сервис, service/offers/ — спецпредложения (8 страниц)
  finance/                кредит, лизинг, страхование
  about/                  о компании и команда
  contacts/               контакты и карта
  legal/                  правовые документы
  404.html                страница «не найдено»
  assets/, images/        стили, скрипт карусели, изображения
  robots.txt              индексация закрыта (это тестовая версия)
  vercel.json             настройка адресов для Vercel

КАК ВЫЛОЖИТЬ НА VERCEL (быстрее всего)
  1. vercel.com → Add New → Project → Deploy without Git / Upload.
  2. Перетащить СОДЕРЖИМОЕ этой папки (не саму папку).
  3. Framework Preset: Other. Build Command и Output Directory оставить пустыми.
  4. Deploy → получите адрес вида pcm-test.vercel.app.

ЧЕРЕЗ GITHUB
  Создайте отдельный репозиторий (например pcm-test), залейте содержимое папки,
  затем в Vercel: Add New → Project → выберите репозиторий → Framework: Other → Deploy.
  Для GitHub Pages: Settings → Pages → Branch: main, папка / (root). Ссылки относительные,
  поэтому сайт работает и в подпапке вида username.github.io/pcm-test/.

ЧТО НЕ РАБОТАЕТ В ТЕСТОВОЙ ВЕРСИИ (и это нормально)
  - Формы не отправляют заявки — вместо письма показывается подсказка с телефоном.
  - Админ-панели и импорта каталога нет: страницы «запечены» из data/*.json на момент сборки.
  - Обновить контент = пересобрать статику (попросите — соберу заново из свежих JSON).
  - Файл открывать двойным щелчком с диска не стоит: ссылки на разделы рассчитаны
    на веб-сервер. Для локального просмотра: python3 -m http.server в этой папке.

БОЕВОЙ САЙТ
  Полная версия с админкой и формами — репозиторий pcm2-site, ставится на PHP-хостинг
  (nic.ru). Vercel для неё не подходит: PHP там не исполняется.
